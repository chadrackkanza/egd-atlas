# EGD Atlas

Application React de cartographie territoriale pour la RDC, conçue pour explorer des cartes interactives, générer des atlas, consulter des données et gérer des exports.

## Fonctionnalités

- Tableau de bord de synthèse
- Carte interactive avec couches thématiques
- Génération de cartes et d’exports
- Recherche de lieux et d’infrastructures
- Catalogue de données et historique des actions

## Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Chakra UI
- React Leaflet
- Recharts

## Scripts

- `npm run dev` : démarre le serveur de développement
- `npm run build` : construit la version de production
- `npm run lint` : contrôle la qualité du code

## Organisation

- `src/App.tsx` : point d’entrée de l’interface
- `src/pages/` : écrans de l’application
- `src/components/` : composants UI et layout
- `src/data/mockData.ts` : données de démonstration
